# OllaCercana

## Justificacion patrones

- Observer: Notificaciones push (FCM) y actualización en tiempo real de disponibilidad via WebSockets.

- Chain of Responsibility: Cadena de moderación para reportes y perfil pausado si la calificación cae de 3.5★.

- Iterator / Composite: Filtrado y busqueda de platos.
